## Discovery call structure

1. Confirm context: treatments/services, booking channels, current admin tools.
2. Map one journey out loud.
3. Identify manual chase points.
4. Ask value question: “If this saved 5–10 hours/week or reduced missed bookings, what would that be worth?”
5. Recommend the first workflow only.
6. Close the audit.

## Objection handling

**“We already have a booking system.”**

Perfect — we’re not trying to replace it. We usually work around the existing booking system and fix the gaps between booking, forms, reminders, follow-up and reviews.

**“We’re not ready for AI.”**

That’s sensible. The audit is workflow-first, not tool-first. If AI is unnecessary, we won’t force it — the goal is simply less manual admin.

**“Can you send information?”**

Of course. I’ll send the short version. If it resonates, the next step is a 30-minute call to choose one workflow for the audit.

**“What does implementation cost?”**

The audit is £500. Implementation starts from £2,500 for one fixed-scope workflow, and the audit fee comes off that if you proceed.
