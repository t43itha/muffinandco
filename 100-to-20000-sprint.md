# Muffin & Co £100 → £20,000 Sprint

**Created:** 2026-05-06 19:25 BST

## Strategy choice

The fastest route is not ads, dropshipping, affiliate content, or low-ticket products. With £100 and Tabby's background, the highest-probability route is a high-ticket B2B service sold directly to appointment-led clinics.

**Core offer:** 72-hour AI Admin Audit → fixed-scope Implementation Sprint.

- **Audit:** £500, credited against build if they proceed.
- **Build:** from £2,500 fixed scope.
- **Target math:** 8 implementation sprints × £2,500 = £20,000.
- **Alternative path:** 10 audits × £500 + 5 builds × £3,000 = £20,000.

## Why this route

- Clinics have high client value, admin burden, reminders/forms/follow-ups/reviews, and no-show leakage.
- They are easier to reach directly than broad SMEs.
- The work uses existing strengths: consulting, workflow design, low-code/Appian thinking, AI automation, premium service tone.
- £100 is enough because we do not need paid ads; we need targeted outreach and calls.

## Offer details

### 1. 72-hour AI Admin Audit — £500

Deliverables:
- 30-minute discovery call.
- One workflow map: e.g. new enquiry → consult booking → pre-treatment form → reminder → aftercare → review request.
- Automation blueprint: triggers, tools, messages, owner, expected time saved.
- One quick-win automation spec ready to build.

Positioning:
> “We’ll show you exactly where your clinic is losing time in admin and what to automate first. If we build it, the audit fee comes off the implementation.”

### 2. Implementation Sprint — from £2,500

Deliverables:
- One approved workflow built end-to-end.
- Client-facing message copy in the clinic's tone.
- Forms/templates/automation set-up.
- Testing checklist.
- Handover documentation and 7-day settling support.

Example sprint scopes:
- No-show reduction: confirmations, reminders, reschedule links, deposit nudges.
- Post-treatment: aftercare sequence, check-in, photo prompt, review request.
- Enquiry follow-up: missed call/email/Instagram DM triage to booked consultation.

## Daily operating rhythm until first £500

### Morning: prospecting block

- Add 30 clinics to the lead sheet.
- Score each: aesthetic/private, website present, visible booking friction, visible forms/reviews/social activity.
- Find owner/practice manager/contact.

### Midday: outreach block

- Send 30 personalised emails.
- Call the top 10 with a short, calm opener.
- Log response status.

### Afternoon: proof block

- For 3 best prospects, create a mini teardown: 3 specific admin leaks and 1 automation idea.
- Follow up with the teardown if they do not reply.

### Evening: iteration block

- Improve subject lines and opening sentence based on responses.
- Build one reusable workflow demo/spec from common clinic pain points.

## Daily targets

- 30 new prospects/day.
- 30 emails/day.
- 10 calls/day.
- 3 personalised mini-audits/day.
- Goal: 1 booked call per 30–50 targeted outreaches.
- Goal: first £500 paid audit within 7 days.

## Qualification questions for calls

1. How are new enquiries currently handled across phone, email, booking form, and Instagram?
2. Where do clients drop off before booking?
3. What reminders/forms/aftercare messages are manual today?
4. What happens when a client misses a call or does not complete forms?
5. If one admin workflow could run without staff chasing it, which one would you choose?
6. What would saving 5–10 admin hours/week be worth to the clinic?
